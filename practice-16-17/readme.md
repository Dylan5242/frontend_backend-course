# Notes App (PWA) с WebSocket, Push-уведомлениями и HTTPS

## Описание проекта

В рамках практических работ было разработано веб-приложение «Заметки» со следующими возможностями:

- использование WebSocket (Socket.IO) для обновлений в реальном времени
- поддержка push-уведомлений (Web Push API)
- работа по защищённому протоколу HTTPS
- реализация архитектуры App Shell
- поддержка оффлайн-режима (Service Worker + Cache API)
- система напоминаний с отложенными уведомлениями

Приложение позволяет создавать заметки, синхронизировать их между клиентами и получать уведомления даже при закрытом приложении.

---

## Функциональность

### Основные возможности

- создание и хранение заметок в localStorage
- добавление напоминаний (дата и время)
- использование уникального идентификатора для каждой заметки

### WebSocket (Socket.IO)

- подключение к серверу
- отправка события `newTask` при добавлении заметки
- получение события `taskAdded` от сервера
- отображение уведомлений в реальном времени

### Push-уведомления

- подписка и отписка через Push API
- отправка уведомлений с сервера
- уведомления о новых задачах
- поддержка действий в уведомлениях (например, «Отложить на 5 минут»)

### Напоминания

- установка времени напоминания
- планирование уведомлений на сервере с использованием `setTimeout`
- хранение активных таймеров
- возможность отложить напоминание

### PWA и оффлайн-режим

- регистрация Service Worker
- кэширование ресурсов:
    - App Shell — стратегия Cache First
    - динамический контент — стратегия Network First
- работа приложения без подключения к сети

### HTTPS

- настройка локального HTTPS с помощью mkcert
- обеспечение работы Service Worker, Push API и Notification API

## Установка и запуск

### Установка зависимостей

```bash
npm init -y
npm install express socket.io web-push body-parser cors
```
### Создание ключей

```bash
npx web-push generate-vapid-keys
```

позже вставить их в файл server.js  
const vapidKeys = {
publicKey: 'ВАШ_PUBLIC_KEY',
privateKey: 'ВАШ_PRIVATE_KEY'
};
### Запуск сервера

```bash
node server.js
```
